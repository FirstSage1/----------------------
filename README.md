# Простой эхобот

## Структура

- `src/bot/main.py` — инициализация и polling; `__main__.py` вызывает эту точку входа.
- `src/bot/config.py` — загрузка `.env` и явного прокси.
- `src/bot/routers/` — команды `/start`, `/help` и повтор сообщений.
- `src/bot/services/text.py` — независимый от Telegram текстовый сервис.
- `src/bot/keyboards/` — клавиатура справки.
- `src/bot/utils/logging.py` — журналирование с сокрытием секретов.
- `tests/` — проверки сервиса и обработчиков.

## Проверка

Windows: `.\.venv\Scripts\python.exe -m pytest -q`.
macOS/Linux: `.venv/bin/python -m pytest -q`.
Тесты не отправляют сообщения в Telegram.

## Развёртывание, обновление и откат

1. Подготовьте отдельную папку релиза и её `.venv`, установите `requirements.txt`.
2. Настройте `BOT_TOKEN` и необязательный `BOT_PROXY` в `.env`. Не публикуйте `.env` и журналы.
3. Запустите тесты, остановите прежний экземпляр бота, запустите новый из папки релиза командой из раздела «Запуск».
4. Проверьте `/start`, `/help`, текст и фотографию в личном чате. Для постоянной работы выполните `./install_autostart.ps1`: скрипт создаст задание Планировщика Windows, которое запускает бота при входе в систему.
5. Перед обновлением сохраните предыдущий релиз и его окружение. Для отката остановите новый процесс и запустите предыдущий релиз с его `.venv` и действующим токеном. Одновременно должен работать один процесс polling.

## Диагностика

- Ошибка токена: проверьте `BOT_TOKEN` локально, не отправляйте его в чат или журнал.
- Ошибка сети: проверьте интернет или явно заданный `BOT_PROXY`.
- Конфликт polling: остановите второй экземпляр, использующий тот же токен.
- Ошибка импорта: запускайте Python из `.venv`, установив зависимости этого проекта.
- После закрытия терминала или выключения компьютера бот не отвечает: программа должна продолжать работать.

Бот повторяет сообщения пользователя в Telegram и умеет вести диалог с AnyModel в режиме `/chatgpt`. Он написан на Python с использованием `aiogram` и загружает настройки из файла `.env`.

## Подготовка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите Python 3.10 или новее. В папке проекта создайте виртуальное окружение и установите зависимости:

### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### macOS и Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

3. Если `.env` ещё нет, скопируйте `.env.example` в `.env` и укажите токен:

```dotenv
BOT_TOKEN=123456:your-token-from-BotFather
ANYMODEL_API_KEY=your-anymodel-api-key
ANYMODEL_MODEL=am/gpt-5.6-terra
ANYMODEL_BASE_URL=https://anymodel.org/v1
```

## Запуск

В PowerShell из папки проекта (активация окружения не требуется):

```powershell
.\.venv\Scripts\python.exe -m src.bot
```

Либо запустите готовый скрипт из PowerShell:

```powershell
.\run_bot.ps1
```

Если PowerShell запрещает выполнение скриптов, используйте команду с `python.exe` выше.

На macOS и Linux:

```bash
.venv/bin/python -m src.bot
```

Дождитесь строки «Бот запущен», затем отправьте боту `/start` и любое сообщение в Telegram. Для диалога с LLM задайте `ANYMODEL_API_KEY`, отправьте `/chatgpt`, затем вопросы; `/stopchatgpt` выключает режим. Оставьте терминал открытым: бот отвечает, пока работает программа. Для остановки нажмите `Ctrl+C`. Запускайте только один экземпляр бота с этим токеном. Файл `main.py` содержит отдельный учебный пример; для бота используйте `python -m src.bot`.

## Автозапуск после перезагрузки Windows

В режиме `/chatgpt` перед запросом к ИИ появляется отдельное сообщение
«Бот печатает…». Оно остаётся в переписке до доставки ответа, после чего
удаляется. При ошибке ИИ статус заменяется текстом ошибки. Системный индикатор
набора текста также обновляется во время ожидания. После перезапуска бота
нужно снова отправить `/chatgpt`: активный режим хранится в памяти процесса.

Если AnyModel вернул HTTP 200 без текста или с неполной структурой ответа,
бот пробует следующие резервные модели. Ошибка выводится только после
исчерпания маршрутов. Незавершённый вопрос не добавляется в историю диалога.
Резервные запросы могут увеличить время ожидания и расход баланса AnyModel.

Один раз выполните в PowerShell из папки проекта:

```powershell
.\install_autostart.ps1
```

Скрипт создаёт задание `TelegramBotAdvancedVibecoding` для текущего пользователя.
При каждом входе в Windows оно запускает бота в фоне без ограничения на 72 часа.
Если Python завершится, `run_bot.ps1` повторит запуск через 15 секунд, в том числе
после исправления `.env`. При аварийном завершении самого скрипта Планировщик
повторяет запуск через минуту (до 999 попыток). Второй запуск `run_bot.ps1`
не создаёт ещё одного бота благодаря блокировке. Ручной `python -m src.bot`
обходит эту блокировку: не запускайте его при работающем задании.

Скрипты `.ps1` сохраняйте в UTF-8 **с BOM**: Windows PowerShell 5.1 иначе
может неверно прочитать русский текст и завершиться до запуска Python.
Бот работает при включённом ПК, активном сеансе пользователя и доступном интернете/прокси.
Сон, выключение ПК и выход из сеанса прерывают работу.

Проверка состояния и журнала:

```powershell
Get-ScheduledTask -TaskName TelegramBotAdvancedVibecoding
Get-ScheduledTaskInfo -TaskName TelegramBotAdvancedVibecoding
Get-Content .\logs\bot.log -Tail 30 -Encoding UTF8
```

Ожидается состояние `Running` и запись «Бот запущен. Ожидание сообщений.»
в журнале. `LastTaskResult = 267009` означает, что задача ещё выполняется.
Журнал хранит до четырёх файлов по 2 МБ с сокрытием ключей; не публикуйте его.
Перед обновлением или откатом остановите задание:
`Stop-ScheduledTask -TaskName TelegramBotAdvancedVibecoding`, убедитесь, что
дочерний Python тоже остановлен, замените файлы релиза, запустите тесты
и снова выполните `install_autostart.ps1`.

Чтобы отключить автозапуск, выполните:

```powershell
.\uninstall_autostart.ps1
```

## Соединение с Telegram

Бот подключается напрямую, если `BOT_PROXY` не задан. Если доступ к Telegram обеспечивается программой VPN/прокси, задайте её адрес явно в `.env`:

```dotenv
BOT_PROXY=http://127.0.0.1:10809
```

Адрес выше — пример; порт должен совпадать с настройками вашей программы. Пустой или отсутствующий `BOT_PROXY` означает прямое подключение.

Если появляется сообщение о соединении с Telegram API, проверьте интернет и VPN: бот работает через Telegram Bot API и не сможет получать сообщения при блокировке доступа к `api.telegram.org`.

Настройка прокси соответствует [документации aiogram](https://docs.aiogram.dev/en/latest/api/session/aiohttp.html).
